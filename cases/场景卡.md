## 场景 1｜半小时通读一篇论文

**什么时候会卡住**：下载了十几篇文献，不知道哪篇值得精读，哪篇扫一眼就该扔。

**提示词**：

```
你是一名学术研究助理。下面是我要读的论文。请按四步输出：
1. 一句话概括：这篇论文想回答什么问题。
2. 论证骨架：用 3–5 个短句还原它的论证顺序（研究问题 → 方法/数据 → 发现 → 结论）。
3. 关键词表：列出 5 个关键词，每个配一句它在文中的原意。
4. 与我相关的部分：一句话说明这篇和我的「XX 研究」有什么关系。
要求：全部用中文，控制在 300 字以内，跳过背景铺陈直接给结论。
如果你判断这篇质量存疑，直接说存疑在哪一点。

论文如下：
【粘贴论文全文或摘要】
```

**前后对比**：

> ✏️ 以前：打开一篇英文文献从头读到尾，边读边猜它值不值得引（约 2 小时）
> ✏️ 现在：先出结构和结论，判断完再决定要不要精读**（约 20 分钟）

## 场景 2｜一堆散文件的整理决策

**什么时候会卡住**：面对几十份同类文件，命名混乱、不知道按什么规则分、也不知道哪些可以直接丢。

**提示词**：

```
我在整理一批同类文件，目标是快速判断「留 / 待定 / 丢」。请做两件事：

1. 先给我一套整理决策：文件夹怎么分层、文件名统一成什么格式（用「日期-人名-事项」这类）、
   哪些情况可以直接丢弃。
2. 按下面的格式，把我贴进来的文件信息转成一张 Markdown 表格：
   文件名 | 关键信息1 | 关键信息2 | 判断 | 理由一句话

要求：理由不超过 15 个字；信息看不出来就写「信息不足」，不要替我猜。

原始信息如下：
【粘贴文件名清单或内容说明】
```

**前后对比**：

> ✏️ 以前：46 份简历逐个点开，人工抄录字段、肉眼判断去留（约 2 小时）
> ✏️ 现在：贴清单进去，直接出带判断列的表格，只做复核（约 30 分钟）

## 场景 3｜检索政策和文献的入口

**什么时候会卡住**：知道要查什么主题，但不知道去哪个库查、用什么词查、这个领域谁绕不开。

**提示词**：

```
我是公共管理专业的学生，正在研究【填研究主题】。请给我一条完整的检索路径：

1. 三个该主题的核心检索渠道，各自适合什么（中文政策 / 中文学术 / 外文学术）。
2. 每个渠道给 5 组中文检索词、3 组英文检索词，按「宽 → 窄」排列。
3. 这个领域绕不开的 2 位代表学者、2 份必读文献或政策文件。
4. 提醒我这个主题常见的检索陷阱（比如同一概念在政策里换了说法、旧版被新版替代）。

要求：不要编造具体的条款号、页码和发表年份，不确定的地方明确写「需自行核对」。
```

**前后对比**：

> ✏️ 以前：在知网和政府网站上一遍遍改关键词试，靠运气翻（约 5 小时）
> ✏️ 现在：先拿到渠道和词表再进库，直奔代表学者和必读文献（约 60 分钟）

## 场景 4｜数据出图，从「不会代码」开始

**什么时候会卡住**：手上有一份数据，知道要说明什么，但不知道画什么图、也不会写代码。

**提示词**：

```
我有一份数据，字段如下：【例如：城市 | 年份 | 指标A | 指标B】（粘贴真实表头）

请做三件事：
1. 判断这份数据最值得呈现的结论，最多 2 条。
2. 每条结论推荐一种图，并说明为什么选它（饼图只在分类不超过 5 个时用）。
3. 给一段可以直接运行的 Python 代码（matplotlib 或 plotly）生成这张图。

代码要求：中文标题、中文轴标签、配色不超过 3 种；每一行代码的作用用中文注释写清楚，
因为我零编程基础，看不懂「df.groupby」这种没解释的写法。
```

**前后对比**：

> ✏️ 以前：先在 Excel 里反复试着折线图，试不出来就找人帮忙（约 5 小时）
> ✏️ 现在：贴表头就出图，附一段带中文注释的代码（约 20 分钟）

## 场景 5｜汇报稿和演讲提纲

**什么时候会卡住**：内容都懂，但不知道怎么组织开场、怎么收尾，也怕被追问时答不上来。

**提示词**：

```
我要在【课堂汇报 / 组会 / 答辩】上讲【主题】，时长【X】分钟。
听众是【老师 / 同学 / 企业新人】，他们最关心【……】。

请输出三部分：
1. 一页提纲：开场钩子 → 三个支撑点 → 收尾一句话。
2. 正文稿：口语化，短句为主，每段不超过 3 行。
3. 三个最可能被追问的问题，各配一个 30 秒的回答版本。

要求：不要 PPT 汇报腔（避免「非常感谢大家给我这个机会」这类开场）；
不要用【首先/其次/最后】串联，改用「第一」「第二」或直接列点。
```

**前后对比**：

> ✏️ 以前：对着空白 PPT 憋开场、来回挪结构，讲稿写完还得另拟问答（约 1 小时）
> ✏️ 现在：提纲、正文、追问版答案一次出齐（约 10 分钟）

## 场景 6｜学术文章的翻译

**什么时候会卡住**：外文文献读得懂大意，但要落在自己的论文里时，译出来一股翻译腔。

**提示词**：

```
请把下面这篇文章翻译成中文，要求：

1. 学术语域，但句子写短；避免多层嵌套的翻译腔。
2. 专业术语首次出现时中英文并列，例如「政策工具（policy instruments）」。
3. 保留原文的段落结构和层级。
4. 译完附一张术语对照表，不超过 10 条。
5. 遇到有歧义的句子，用【译注：……】标出来说明歧义在哪，替我做的决定请标明。

原文如下：
【粘贴原文】
```

**前后对比**：

> ✏️ 以前：一段段手工译，同一个术语前后译法还不统一（约 3 小时）
> ✏️ 现在：一次成稿加一张术语表，我只做校对（约 30 分钟）

## 场景 7｜长文献压成半页摘要

**什么时候会卡住**：一篇重要文献十几页，看完了留不下任何可以搬到自己文章里的东西。

**提示词**：

```
请把下面这篇文献压缩成不超过半页 A4（约 350 字）的摘要卡片，严格按这个结构输出：

- 研究问题（1 句）
- 方法与数据（1 句，必须标明样本量或时间跨度）
- 核心发现（最多 3 条，每条 1 句）
- 对我的用处（1 句）
- 它的局限（1 句）

禁止：写背景铺陈、写评价性套话、大段引用原文。

文献如下：
【粘贴文献】
```

**前后对比**：

> ✏️ 以前：十几页通读一遍，读完说不出这篇到底给了自己什么（约 1 小时）
> ✏️ 现在：出一张 350 字的卡片，直接进自己的文献库（约 20 分钟）
